One funny fortune cookie line for an AI agent, entered in make.fun's "Fortune Cookie for an AI Agent" bounty.

## Run it

```sh
python3 main.py
```

The program writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
